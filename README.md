# 📚 StudyHub
### Student Learning Resources Website

**Learn Better. Grow Smarter. Achieve More.**

---

## 🌟 About the Project

StudyHub is a multi-page educational website designed to provide students with an organized platform to explore learning resources and programming technologies.

Built using **HTML5 and CSS3**, the website offers a simple, user-friendly interface with consistent navigation across multiple pages.

## ✨ Features

- 🏠 **Home Page** – Introduction to the StudyHub platform.
- 📖 **Learning Resources** – Explore information about popular programming technologies.
- 💻 **Technology Topics** – HTML5, CSS3, JavaScript, Python, and Java.
- 📩 **Contact Page** – A form for submitting messages and inquiries.
- 🔗 **Page Navigation** – Connected pages for smooth navigation.
- 🎨 **Responsive Styling** – Clean layout, attractive colors, and interactive hover effects.

## 🛠️ Technologies Used

| Technology | Description |
|:---|:---|
| HTML5 | Structures website content and pages |
| CSS3 | Handles styling, layout, colors, and visual effects |
